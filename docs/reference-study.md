# 参考站研究与本次重做

研究来源：[pet-the-cat.pages.dev](https://pet-the-cat.pages.dev/)，2026-11-25 下载其公开 HTML。原站公开页面自身携带解码器和资源，不需要访问账户、服务端或非公开接口。

## 本地研究文件

- `research/reference/index.html`：原始公开页面，UTF-16LE 编码。
- `research/reference/bootstrap.js`：页面自带的解包入口。
- `research/reference/app.html`：解析出的界面与样式。
- `research/reference/app.js`：格式化后的公开客户端代码，仅供本地研究。
- `research/reference/directory.json`：照片索引和原始裁切框。
- `research/reference/photos.bin`：公开照片数据区。

研究目录已在 `.gitignore` 中排除，不作为本项目客户端代码发布。

## 对质感影响最大的结构

原站把素材与脚本装入单一页面。解析后得到约 4 万字符的界面、12.6 万字符的客户端脚本，以及 27 项 AVIF 图片资源。猫身和尾巴分开，手掌有张开与抓握两张照片；背景是一张实际带窗光的亚麻图片。

猫身网格使用独立位置、纹理和光照数据。按压既改变轮廓，也改变接触区域的毛发采样和明暗；尾巴拥有单独的骨架与图像条带。原站还处理了毛流、头颈权重和手指姿态。本次没有把整套原站脚本直接嵌入项目，而是使用自己的 React 组件和 WebGL 渲染器实现当前要求。

参考站图像以 1517 × 935 为坐标，照片经过透明边界裁切。当前渲染器将各只猫的图片放入统一参考画幅，再从透明轮廓估算尾根。猫身和尾巴分别加载和绘制。

## 当前视觉与功能

当前画布采用窗边羊羔绒背景和深绿控件，工具栏提供 13 只猫与正背面切换。手机竖屏下工具栏分行。

历史版本曾使用原作者 [@zubububu 的参考站](https://pet-the-cat.pages.dev/)中的部分照片。当前网页使用本项目新生成的独立猫咪图集、手掌和背景，生成记录见 `image-generation.md`。

当前 WebGL 网格用弹簧响应模拟局部压陷。毛流位移在放手后渐退，尾巴以定长骨架模拟拉直和卷回。接触点从身体进入尾巴区域时，手掌过渡到握姿。
